# boostmap

Boost validation gates for map inputs before they hit prod.

**Site:** https://theworker02.github.io/boostmap/

## Install / run

```bash
git clone https://github.com/theworker02/boostmap.git
cd boostmap
node src/cli.js
node --test
```
